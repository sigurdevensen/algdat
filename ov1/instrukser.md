# Instrukser for kjøring

## Krav
- [Rust og Cargo](https://www.rust-lang.org/tools/install) må være installert.

## Kjør programmet

Åpne terminal i mappen og kjør:

```
cargo run
```
Eventuelt:
```
cargo build && cargo run
```

Programmet vil skrive ut beste kjøpstidspunkt, beste salgstidspunkt, høyeste profit og hvor lang tid algoritmen brukte.
